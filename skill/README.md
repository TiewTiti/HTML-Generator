# กติกาการทำงาน — Login Studio ชุดใหม่

สตูดิโอใหม่อยู่ที่ `/workspace/studio/` ไฟล์เดิมที่รากโปรเจกต์ (`index.html`, `app.js`, `style.css`) ใช้เป็นต้นแบบพฤติกรรม ไม่แก้ทับ

## ก่อนลงมือทุกครั้ง

1. เสนอสิ่งที่จะทำ แล้วรอให้ยืนยัน
2. ทำทีละช่วง ตรวจในเบราว์เซอร์ก่อนไปช่วงถัดไป
3. แผนใช้สกิลใน `skill/superpowers/` (`writing-plans`, `executing-plans`, `verification-before-completion`)

## หน้าตา

- ยึดไฟล์ Figma **Login Studio — Variant B** หน้า **ลำดับขั้น**
- ทางเข้าแยกนักเรียน (น้ำเงิน) กับครู (ส้ม)
- งานในสตูดิโอเดิน HTML → CSS → code
- ไอคอนแท็กใช้ไฟล์ที่ดึงจากเฟรม Figma ใน `studio/public/icons/`
- ไอคอนอย่างระฆังใช้ Lucide ผ่านปลั๊กอิน `@iconify/tailwind4` เพราะชื่อเลเยอร์ใน Figma เป็นชุดเดียวกัน (`icon-bell`)

## พฤติกรรมที่ยึดจากโปรเจกต์เดิม

- ไม่มี backend ร่างอยู่ใน `localStorage`
- รหัสครู `759212` ล็อกเฉพาะเว็บต้นแบบ นักเรียนวางแท็กและแต่งสีเองได้
- ช่องรหัสครูขึ้นเป็นจุด ไม่โชว์ตัวเลข
- เพิ่มชิ้นได้ที่แผงขวาที่เดียว สลับที่ด้วยปุ่มขึ้นและลง
- มีทั้งหน้าเข้าสู่ระบบและหน้าสมัคร แยกกระดานกัน
- ลบกระดานต้องกดยืนยันก่อน
- ไฟล์ที่ดาวน์โหลดเป็น HTML ไฟล์เดียว เปิดออฟไลน์ได้ ไม่ฝัง Tailwind หรือ CDN
- ข้อความบนจอสั้น เป็นภาษาที่ใช้ในเฟรม
